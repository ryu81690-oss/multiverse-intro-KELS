# multiverse-intro-KELS

「교육심리 연구의 신뢰성 향상을 위한 멀티버스 분석: 분석 선택에 따른 결론의 강건성 점검」의 분석 코드와 자료 처리 절차, 부록 실태 분석의 코딩 자료.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `01_multiverse_analysis.R` | 자료 구성, 점수화(종단 확인적 요인분석 포함), 192개 설정 추정, 본문 수치 산출 |
| `02_figures.R` | 본문 그림 1~3 (컬러판, 흑백판) |

## 원자료

한국교육종단연구 2013(KELS 2013) 원자료는 재배포할 수 없어 저장소에 포함하지 않았다. 한국교육개발원의 자료 이용 절차에 따라 신청하여 받은 뒤, 아래 네 파일을 `02 연구데이터` 폴더에 둔다.

| 차수 | 학년 | 파일 |
|---|---|---|
| 2차(2014) | 초6 | `1. L2Y2S_학생.sav` |
| 3차(2015) | 중1 | `2. L2Y3LT_학습자특성.SAV` |
| 5차(2017) | 중3 | `2. L2Y5LT_학습자특성.sav` |
| 7차(2019) | 고2 | `2. L2Y7LT_학습자특성.sav` |

사용 문항
- 내재적 동기(문1): 교과별 3문항(몰입, 중요성, 재미), 4점 척도. 2차의 재미 문항은 "○○를 공부하는 것이 재미있으므로, ○○를 포기하지 않겠다"로 이후 차수("○○를 공부하는 것이 재미있다")와 문구가 다르다.
- 교과별 자기효능감(2차 문5, 3·5·7차 문4): 교과별 4문항. 2·3·5차는 수학·영어·국어 순, 7차는 국어·수학·영어 순이며 코드에서 차수별로 맞추었다.
- 결측 코드(-1~-5)는 결측으로 처리한다.

## 분석 설정

추정 대상: 초6~고2(2·3·5·7차) 내재적 동기의 학년당 변화(SD/년). 질문 1은 세 교과 평균, 질문 2는 국어.

| 층위 | 선택 | 대안 |
|---|---|---|
| 자료 정의 | 표본 | 전체 / 2시점 이상 / 완전 응답 |
| 자료 정의 | 이상치 | 미제거 / ±3SD 제거(점수 유형별 전체 분포 기준) |
| 측정과 조작화 | 점수화 | 3문항 평균 / 중요성 제외 / 요인점수(강한동일성) / 요인점수(부분동일성) |
| 전처리 | 표준화 기준 | 기준 시점 SD / 통합 SD |
| 분석 모형 | 변화 형태 | 선형 / 구간(중3 매듭, 전·후반 기울기 평균) |
| 분석 모형 | 추정 모형 | 통합 회귀(개인 군집 강건 표준오차) / 다층성장(무선 절편·기울기) |

요인점수: 교과별로 네 시점을 하나의 종단 확인적 요인분석(MLR, FIML, 같은 문항의 시점 간 잔차 공분산 허용)으로 추정한다. 강한동일성은 적재치와 절편을 네 시점에 동일하게 제약하고, 부분동일성은 문항마다 절편 제약을 하나씩 풀어 강한동일성 모형과 비교(척도화 카이제곱 차이 검정)했을 때 적합도 개선이 가장 큰 문항의 절편 제약을 풀어 준다. 요인점수는 회귀 방식으로 산출하며, 세 교과 평균은 교과별 요인점수를 초6 기준으로 표준화한 뒤 평균한다.

기준 설정(그림 3): 세 교과 평균, 3문항 평균, 2시점 이상, 이상치 미제거, 기준 시점 SD, 선형, 통합 회귀. 기준 설정에서 교과, 시점 선택, 시점별 표준화, 시간 단위(조사 차수), 자기효능감 통제를 하나씩 바꾼 결과가 `one_switch_results.csv`에 저장된다.
